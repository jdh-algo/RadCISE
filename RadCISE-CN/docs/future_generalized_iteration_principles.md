# RadCISE-CN 后续泛化迭代原则

1. 不针对单个病例、单个模型或当前评测集中的具体错误写特例。
2. 每次修改必须先抽象为更一般的临床语义问题，例如：阴性句极性、主病灶与属性边界、低风险异常分层、CTPA 核心阴性、局灶-弥漫尺度冲突等。
3. prompt 示例可以使用自造的中文医学影像报告片段，但不得直接使用当前评测样例原文。
4. JSON schema 和枚举值尽量保持稳定，避免破坏既有统计流程。
5. 中文术语补丁应覆盖一类问题，而不是一个词。例如加入“少许/少量/微量/轻度/点状/条索/陈旧/钙化/退变”作为低重要性语义族，而不是只为某个病例加入一个词。
6. 每次修改后至少验证：
   - 原 3 例；
   - 13 例校准集；
   - 代表性模型报告样例；
   - 多次重复稳定性；
   - A1/A2/A3/N 分布和 guard warning 比例。
7. 若分数变化明显，应先判断是预期分数不合理、模型报告质量差异、还是 RadCISE-CN 分层/匹配规则问题，不应直接以分数高低作为修改依据。
8. 中文化分支应与英文主线结果区分记录，避免把不同 prompt 语言版本的分数直接混用。
