CASE-RELATIVE CLINICAL-IMPACT FRAMEWORK
Tier assignment must be based on the role of each concept in the whole Ref+Gen report pair, not on a fixed disease-name rule or a fixed keyword. Do not add disease-specific special cases. Use the following general decision tests:
1. A1 test: Would an omission, false addition, or core contradiction of this concept materially change the main diagnosis/impression, severity/risk category, urgency, treatment strategy, procedural candidacy/planning, or near-term follow-up priority? If yes, A1.
2. A2 test: If not A1, would the concept still materially affect staging/severity/risk/procedure planning/differential diagnosis/follow-up quality, or be a major attribute of an A1 process? If yes, A2.
3. A3 test: If it is real but mostly incidental, mild, optional, non-decisive, or a dependent detail of an already recognized parent process, A3.
4. N test: If it is a routine negative/normal statement, N unless excluding that finding is central to the clinical question.
These are principles, not disease-specific rules. Examples must be interpreted as broad categories: main mass/infection/hemorrhage/infarct/obstruction = possible A1; severe independently management-changing invasion/occlusion/perforation/bleeding = possible A1/A2; small incidental cyst/calcification/trace fluid/mild chronic change = usually A3; routine negative screen = usually N.

CONFLICT QUALITY PRINCIPLE
Use core_conflict only for a true same-axis contradiction that changes the core clinical judgment. If the same abnormal process is present on both sides but there are differences in size, extent, severity, distribution, subtype, local relationship, number, or staging-like attributes, prefer attribute_conflict or substantial/limited rather than core_conflict.

CONCEPT BOUNDARIES
Usually define concepts around:
- dominant primary lesion or dominant disease burden;
- nodal disease if independently staging/management relevant;
- pleural/peritoneal/serosal involvement if independently important;
- clinically significant fluid, gas, obstruction/dilatation, hemorrhage, ischemia, perforation, fracture, vascular invasion/thrombosis;
- clinically independent incidental abnormality;
- clinically meaningful normal/negative assertion.

SPLIT only when a concept is usually assessed separately for diagnosis/staging/prognosis/management/safety, e.g. nodal disease, distant metastasis, definite vascular invasion, definite clinically significant obstruction, clinically significant effusion, free gas/perforation, hemorrhage, independent incidental disease in another organ, or critical negative exclusion.

FOUR-TIER DEFINITIONS
A1 = core abnormality / main-conclusion-level finding. Omission or false addition would materially change the main impression, diagnosis, staging, urgent management, treatment strategy, or follow-up priority. Keep A1 compact and clinically interpretable. A1 should be anchored to imaging-observable disease, not to history/indication labels alone. A1 usually includes dominant disease burden, the main lesion/process, and independently management-changing axes such as nodal disease, definite major serosal involvement, definite major vascular invasion, major obstruction/collapse, or major metastasis.

A2 = important secondary abnormality OR major attribute that remains clinically meaningful even after the A1 parent is recognized. A2 includes: (a) definite local extension/invasion/obstruction/vascular or ductal involvement that could affect staging, operative planning, differential diagnosis, or near-term follow-up; (b) clearly clinically relevant secondary abnormality; (c) major attribute disagreement that materially affects report quality but does not replace the main A1 diagnosis. A2 should be used sparingly and consistently. Do not put routine unilateral negative screening statements into A2 unless they are explicit critical negatives for the exam.

A3 = low-clinical-significance abnormality / optional completeness finding / non-decisive dependent detail. A3 is real but omission usually has little effect on main diagnosis, staging, treatment, or short-term management. A3 includes incidental low-significance abnormalities, small/trace fluid when not clearly clinically decisive, mild nonspecific changes, technical/physiologic observations, and hedged or non-decisive local details related to an already-matched A1 parent. A3 is intentionally used to absorb optional details so they do not destabilize A1/A2.

N = normal/negative description. Ordinary negative screening statements are N. A clinically critical negative can be promoted to A1/A2 only when it is a central reason for the exam or major management decision, for example, when absence of a dangerous acute event, obstructive/ischemic process, perforation-type complication, or distant disease spread is the central clinical question.

A1/A2/A3 TIE-BREAKERS
- If missing it changes the main impression/staging/management, choose A1.
- If it is a key attribute of the main lesion or a meaningful secondary abnormality, choose A2.
- If it is a low-significance incidental/technical/optional finding, choose A3.
- Do not promote every abnormality to A1.
- Do not make a dependent attribute a standalone A1 merely because it is mentioned as a separate SRU.
- If a generated-only finding is hedged (possible, suspected, unclear interface, cannot exclude, may represent, abutment) and is a local detail of an already matched parent lesion, choose A3 or at most A2 unless it is definite and independently management-changing.

SAME-AXIS CONFLICT RULE
Use core_conflict ONLY when Ref and Gen contradict each other on the same clinical axis: same organ/compartment + same property/pathology + opposite presence/absence, wrong side/site, different disease entity, or management-changing contradiction.
Do NOT merge a positive abnormality with a nearby but different normal statement merely to create core_conflict. If related but not the same axis, use separate concepts, or limited/attribute_conflict if partially overlapping.
Examples: "left hydronephrosis" vs "no urinary tract dilatation" = core_conflict. "liver mass 4 cm" vs "liver mass 5 cm" = attribute_conflict. "tumor with fat stranding" vs "no obstruction" = different axes unless one directly denies the other.

MATCH QUALITY
- full: same concept and essential information consistent.
- substantial: same core concept; only minor detail/granularity differences.
- limited: related but incomplete/broader/narrower/partial overlap, still clinically useful.
- attribute_conflict: same lesion/finding exists on both sides, but clinically relevant attributes differ materially (size, margin, density/signal, enhancement, morphology, volume, number, local extension). Core identity remains aligned.
- core_conflict: same clinical axis but materially inconsistent core judgment.
- none: concept appears on one side only.
For unilateral concepts, match_quality must be none. For core_conflict, same_axis_contradiction must be true. If same_axis_contradiction is false, do not use core_conflict.


ADDITIONAL STABILITY RULES FOR FOUR-TIERING
1. A1 core scoring boundary: For an A1 parent lesion/disease concept, match_quality should primarily judge whether the same core disease/lesion axis is present in the same organ/compartment. Do not downgrade an A1 parent concept to limited merely because size, enhancement, margin, number, or local-effect details differ; those are key-attribute disagreements and usually imply attribute_conflict or substantial depending on severity.
2. Dependent local effects: airway narrowing, ductal narrowing, local vessel abutment, surrounding inflammatory change, adjacent consolidation, regional volume change, or local mass effect should be A2 when definite and clinically relevant but dependent on an already matched A1 parent. If hedged/uncertain or not independently management-changing, use A3. Use A1 only if it is definite and independently changes staging/urgent management/treatment.
3. Low-volume fluid rule: small/trace/minimal fluid is A3 by default when incidental or distant from the dominant disease. It can be A2 when it is clinically related to the dominant disease context, affects staging, or is a meaningful complication. It should rarely be A1 unless it is large/tension/infected/hemorrhagic or the main problem.
4. Routine unilateral negative rule: a unilateral negative screening statement (e.g. no lymphadenopathy, no ascites, no duct dilatation, no bone abnormality) is N unless it is a critical negative central to the exam indication or main management decision. Do not place routine negatives in A2/A3 merely because the denied disease would be important if present.
5. A3 purpose: Use A3 to absorb low-significance abnormalities and optional completeness findings so that they do not destabilize A1/A2.
